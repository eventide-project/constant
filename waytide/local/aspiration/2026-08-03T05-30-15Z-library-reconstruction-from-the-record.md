# Library Reconstruction From The Record — Aspiration

**Premise:** the Constant library, together with the logs and records accumulated while it
was built, will be used in an attempt to **reconstruct a library from the start**. The
attempt has **two aims** — that Constant, or a brief facsimile of it, can be recreated under
the control of its own record so as to **conform to** Constant, and that an **entirely new
library** can be created in Constant's image. The artifact the attempt produces will be used
on the website.

## Background & Motivation

The Constant library has been built with an unusually complete record of how it was built.
Beside the code sit 206 decision-log entries, 19 loop records carrying each cycle's hinge and
the options put at the gate, 11 observations, 6 feature records, 2 experiment records, 2
designs, and 5 work-session narratives. That record was written for its own sake — so the
reasoning behind the work would not be lost — and no use has yet been made of it beyond
being read.

The reconstruction asks what the record is worth as **input**: whether a library can be
brought into being from the start out of what was written while the first one was built.
That is a different question from whether the record is readable, and it is the first
question that tests the record rather than merely preserving it.

The result is not private to the project. The artifact goes on the website, which means it
is produced to be shown and read by people who were not present for any of the original
work.

## Vocabulary

- **the record** — the accumulated working-state artifacts under `waytide/local/`: the
  decision log, loop records, observations, feature and experiment records, designs, and
  work-session narratives. Distinct from the **code**, which is the library itself, and from
  the **rules** under `waytide/system/` and `waytide/local/rules/`, which govern how work is
  done rather than recording what was done.
- **the reconstruction** — the attempt: building a library from the start, using the Constant
  library and the record as its source material.
- **under the control of the record** — the record **governs** the reconstruction rather than
  informing it. It is not reference material consulted where convenient; it is what the
  rebuild is conducted by.
- **conform to Constant** — the criterion for the first aim: what results is judged against
  the existing library, which is there to be conformed to.
- **in Constant's image** — the relation the second aim's library bears to Constant. What
  carries over is the manner rather than the result, since there is no original for a new
  library to conform to.
- **facsimile** — a recreation that reproduces Constant in the respects that matter without
  necessarily reproducing all of it. The first aim admits a **brief** one.
- **the artifact** — what the attempt produces and what the website carries. Its form is not
  yet settled (see Out of Scope / Deferred).

## The two aims

The attempt has two aims. They are not a strong and a weak version of one thing — they differ
in whether an original exists to be answerable to, and that difference decides how each is
judged.

**One — Constant recreated, conforming to Constant.** The Constant library, or a brief
facsimile of it, is recreated **under the control of** its own logs and records, so that what
results **conforms to** Constant. The record governs the rebuild. Conformance is the
criterion, and it is available precisely because the original is still there: the result can
be set beside the library it was rebuilt from and the gap read off directly. This is the aim
that tests the record, because a shortfall is attributable — something the record failed to
carry.

**Two — an entirely new library in Constant's image.** A library that is *not* Constant is
created in Constant's image. Nothing here is conformed to, since there is no original the new
library owes anything to; what transfers is the manner of the thing rather than its
substance. This is the aim that tests whether what the record carries **generalizes** — a
record that can only rebuild the library it came from has shown something narrower than one
that can shape a library it has never seen.

The first aim is measurable and the second is not, at least not in the same way. Both are
stated as aims of one attempt rather than being split into a real one and an aspiration.

## Settled

- **2026-08-02** — The Constant library and the record accumulated while building it will be
  used in an attempt to reconstruct a library from the start.
- **2026-08-02** — The attempt has **two aims**, both held: Constant or a brief facsimile
  recreated under the control of its own record so as to conform to Constant, and an entirely
  new library created in Constant's image.
- **2026-08-02** — The record **controls** the recreation. It governs the rebuild rather than
  serving as reference material for it.
- **2026-08-02** — **Conformance to Constant** is the criterion for the first aim.
- **2026-08-02** — The first aim admits a **brief facsimile** — the recreation need not
  reproduce the whole library.
- **2026-08-02** — The artifact the attempt produces will be used on the website.
- **2026-08-02** — The reconstruction gets its own design rather than being recorded in the
  Constant class design or the human-in-the-loop TDD design; neither is about the
  reconstruction.

## Out of Scope / Deferred

Not settled here, and each of them changes the shape of the attempt:

- **How conformance to Constant is judged** — by the suite passing, by the public interface
  matching, by behavior, or by a reading of the result. The criterion is settled; its measure
  is not.
- **How brief a brief facsimile may be**, and which respects it must reproduce to still count
  as one.
- **Whether the two aims are one attempt or two.** They are stated together; nothing settles
  whether they are pursued in sequence, in parallel, or as separate efforts.
- **What the artifact is** — a narrative, a recorded run, a document, a comparison, the
  reconstructed library itself, or some combination — and which website carries it.
- **Whether the reconstruction runs as an experiment.** It is framed as an *attempt*, which
  suggests a question with a forecast and a verdict, but nothing has been declared.
- **What the reconstruction is allowed to use.** Whether the code is available to it or only
  the record; whether the rules travel with it; whether the reconstructor sees the original
  at all.
- **What would count as success**, and against what the result is judged.
- **Who or what conducts it**, and under which gating cadence.
