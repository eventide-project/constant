# `Constant::Import` carries a `refine ::Object` so that `using Constant::Import` gives `import` with no `include` or `extend` and no process-wide footprint — `Object.instance_methods.grep(/import/)` stays empty. `refine ::Object` alone covers `main`, module bodies, class bodies, and instances, because modules and classes are objects; a companion `refine ::Module` was written and then dropped as redundant
