# Including `Constant::Import` at the top level raises `Constant::Error` naming `using Constant::Import` as the remedy, rather than installing the macro — top-level inclusion includes into `Object`, whose singleton class every class inherits from, so `base.extend(Macro)` had been putting `import` on every class in the process. The raise precedes the extend, so nothing is installed. This supersedes 2026-07-26T17-27-23Z-macro-top-level-extend-based and the include-based idiom that replaced it; the refinement is the only top-level form, and it is a breaking change for scripts that included at the top level
