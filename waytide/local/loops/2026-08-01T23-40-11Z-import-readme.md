## Pass 1 — where the raised conditions are documented

**Hinge** — the README described none of the five conditions under which `Import` raises,
while documenting raised errors carefully for `Constant.get`, `Constant()`, and
`Constant::Module#get`. Where the new material goes decides everything else.

**Options** — a section of its own listing all five together, each condition beside the
keyword that causes it, or a `**Raises**` block in each signature section.

**Decision / chat** — the developer first asked **what "refusals" meant**, which exposed
that the word was mine rather than the document's. It came from the deferred item that began
this work — *"Refuse the collision"* — and had been carried through the session unexamined.
The README says **raises**, inline; "refused" appears in it exactly once, for top-level
inclusion.

Re-put in the document's own vocabulary, the choice went to **inline, as the rest of the
README does**.

## Pass 2 — the pattern that choice implied, checked rather than assumed

**Hinge** — none — this corrected an error in pass 1's own options.

**Decision / chat** — the option offered a `**Raises**` block beside `**Returns**`. Grepping
found **no `**Raises**` block anywhere in the README**: raised errors are a sentence appended
to the `**Returns**` paragraph — *"Raises `Constant::Error` when a name is not defined."*
Building what the preview showed would have introduced a section pattern the document does
not have, in the name of matching it. The sentence form was used instead.

## Pass 3 — duplication between the two sections

**Hinge** — the signature and parameters appear twice, in the macro section and the API
section. Whether the new keywords are explained in both or in one with a pointer.

**Options** — none — not gated. The document already explains `alias` in both places with
its own example in each, so the established habit answers it: both, kept parallel.

## Pass 4 — verifying the prose

**Hinge** — none. Documentation states behavior, so the statements are checked against the
library rather than written from memory.

**Decision / chat** — all ten documented claims were run: `except` with a single Symbol and
with a String, `only` with an Array and with a single name, and each of the conditions that
raises and does not. Every one held, including the two **asymmetries** the prose asserts —
that a name given to `only` which the source does not own raises, while the same name given
to `except` is simply not there to omit.

## Outcome
